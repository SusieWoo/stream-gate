# 约束条件与用例清单（微信小程序场景）

对应交底书大纲 S1（约束注入）与第六节（对照实验）。本清单是 demo 的事实来源，代码实现见 `src/constraints/`、`src/rules/`、`fixtures/mp-cases.json`。

---

## 一、约束条件（S1 注入内容）

### 1. 目标平台能力矩阵（`src/constraints/platform-matrix.js`）

目标平台：`mp-weixin`。结构为「平台 × API × 是否支持 × 替代方案」。

| API | 是否支持 | 替代方案 | 原因 |
|---|---|---|---|
| window | 否 | — | 小程序无 window 全局对象 |
| document | 否 | — | 小程序无 DOM |
| location | 否 | uni.navigateTo / uni.redirectTo | 页面跳转须用路由 API |
| localStorage / sessionStorage | 否 | uni.setStorageSync / uni.getStorageSync | 须用小程序存储 API |
| fetch / XMLHttpRequest | 否 | uni.request | 须用小程序网络 API |
| alert | 否 | uni.showToast / uni.showModal | 须用小程序交互 API |
| uni.request / uni.navigateTo / uni.redirectTo | 是 | — | — |
| uni.setStorageSync / uni.getStorageSync | 是 | — | — |
| uni.showToast / uni.showModal | 是 | — | — |
| console.log | 是 | — | — |

### 2. 组件清单（`src/constraints/component-catalog.js`）

uView 子集 5 个组件 + 小程序原生标签白名单（view、text、scroll-view 等 13 个）。

| 组件 | 合法属性（枚举值） | 合法事件 |
|---|---|---|
| u-form | model, rules, labelWidth, labelPosition(left/top) | — |
| u-form-item | label, prop, required, labelWidth | — |
| u-input | value, placeholder, disabled, clearable, type(text/number/digit/password/tel) | input, focus, blur, confirm, clear |
| u-button | type(default/primary/success/warning/error), size(small/medium/large), text, loading, disabled | click |
| u-icon | name, size, color | click |

### 3. 规则集（`src/rules/rules.js`）

| 规则编号 | 适用节点 | 内容 |
|---|---|---|
| R-TPL-001 | 模板元素 | 标签必须存在于组件清单（编辑距离 ≤2 给出最相近合法项） |
| R-TPL-002 | 模板元素 | 属性与属性取值必须合法（含枚举值校验） |
| R-TPL-003 | 模板元素 | 事件绑定目标必须在脚本中声明（模板先于脚本到达时挂起，流结束结算） |
| R-API-101 | 脚本语句 | 禁止调用目标平台不支持的 API |
| R-API-102 | 脚本语句 | uni.* 调用必须在白名单内 |
| R-CC-201 | 条件编译块 | 目标平台切片后不得为空（仅注释或无内容判违规） |
| R-JS-301 | 脚本语句 | 函数调用目标必须先声明 |

### 4. 语法边界（S2 增量解析切分依据）

- 模板元素：开标签到匹配闭标签（栈式扫描，容忍文本与嵌套；自闭合标签直接产出）
- 脚本语句：括号/花括号/方括号配平且以 `;` 或 `}` 收尾（支持多行语句）
- 条件编译块：`// #ifdef X` 到 `// #endif`
